# SBS - Système de Maintenance Préventive

Solution de numérisation du flux de maintenance préventive pour **Substancium Business Services**.

## Architecture

| Module | Technologie | Description |
|--------|-------------|-------------|
| `backend/` | FastAPI + PostgreSQL | API REST centrale |
| `frontend-web/` | React + Vite | Portail superviseur |
| `mobile/` | React Native (Expo) | App techniciens (Offline-First) |

## Démarrage rapide

Voir le `README.md` de chaque module pour les instructions d'installation.

## Planification

Méthodologie Agile (Scrum) — 6 Sprints de 2-3 semaines.
